# Agentic Showcase

A dark, evidence-first technical showcase for a Cartwright site using the full
agentic profile. The design presents live discovery, MCP, OpenAPI, REST, trust,
security and recovery contracts. It deliberately does not ship a numeric
third-party score: a score may only be added after the corresponding public
report has been refreshed and verified.

The interactive inspector fetches same-origin responses from the running site.
No audit screenshots or API payloads are fabricated or bundled as evidence.
