# Cartwright support

Use the channel that matches the problem so it reaches the right place quickly.

## Bugs and feature requests

- [Report an engine bug](https://github.com/Teloz1870/cartwright-template/issues/new?template=bug.yml)
- [Request a feature](https://github.com/Teloz1870/cartwright-template/issues/new?template=feature.yml)
- [Browse existing issues](https://github.com/Teloz1870/cartwright-template/issues)

Include the engine version from `.cartwright/release.json`, the profile from
`.cartwright/profile.json`, your Node version, and a minimal reproduction. Questions about
`create-cartwright` that reproduce in the generated project belong here too; maintainers will
route a CLI-only defect to the CLI repository when needed.

## Setup and documentation

Start with the [quick-start guide](https://cartwright.app/docs/getting-started/quick-start),
the local [`docs/getting-started.md`](docs/getting-started.md), and
[`docs/versioning-policy.md`](docs/versioning-policy.md). If the documented path does not work,
open a bug report so the fix helps the next developer as well.

## Security

Do **not** post a vulnerability in a public issue. Follow [`SECURITY.md`](SECURITY.md) and use
[GitHub private vulnerability reporting](https://github.com/Teloz1870/cartwright-template/security/advisories/new)
or email `security@teloz.net`.

## Store-specific customisation

This public issue tracker covers the Cartwright engine, scaffolder output, shipped design packs,
and documentation. Bespoke store design, migration work, hosting accounts, and third-party service
configuration are outside community support unless the problem reproduces in a clean scaffold.
